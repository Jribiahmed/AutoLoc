# \# AutoLoc

# 

# AutoLoc est une plateforme de gestion de location de véhicules

# pour plusieurs agences.

# 

# \## Objectif du projet

# 

# Gérer les véhicules, les agences, les réservations et les locations

# dans une même application.

# 

# \## Acteurs

# 

# \- Client

# \- Agent d'agence

# \- Responsable d'agence

# \- Administrateur

# 

# \## Premiers cas d'utilisation

# 

# \- Le client consulte les véhicules disponibles et effectue une réservation.

# \- L'agent d'agence traite les réservations et les locations.

# \- Le responsable d'agence suit l'activité de son agence.

# \- L'administrateur gère les utilisateurs et les paramètres de l'application.
